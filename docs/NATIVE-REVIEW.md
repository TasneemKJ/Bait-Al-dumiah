# Arabic strings awaiting native review

No string in this game has been reviewed by a native Arabic reader: all Arabic was written by the maintainers and AI collaborators in a Levantine (Shami) register, and the checks so far are mechanical (`tests/arabic-agreement.test.mjs`, `tests/levantine-copy.test.mjs`, screenshots at phone size in RTL). This file lists the lines added or reworded in the audit rounds of 2026-10-05/06, which are the newest and the least tested by eye. Please read each in the game's context (the "check" column says what to look for) and send corrections as replacements for the key. The earlier body of copy (about 550 keys in `src/locale-data.js`) is also unreviewed; ask for a full pass if there is budget.

Register: colloquial Levantine for UI and narration (`بيكبّر`, `هلّق`, `ناطر`, `لسا`), Modern Standard only for headings and system words (`احفظ`, `الشكر والتراخيص`). Numbers are Arabic-Indic through `Intl` (`ar-JO`). The player is addressed in the masculine by default (see TODO: deliberate, flagged for a decision).

## 1.1 fusha pass (2026-11-13): every changed string

From version 1.1 the register is Modern Standard Arabic (fusha) everywhere: simple, warm, short sentences, no colloquial wording. This replaces the Levantine register described at the top of this file; the older tables above show the pre-1.1 wording and are kept as history. The language picker now reads `العربية` (was `العربية · شامي`).

Conventions used: the player is addressed in the masculine singular, as before (`اضغط`, `أمسك`); Noor and Sami are masculine, Lina feminine; the dolls (`الدمى`) take feminine-singular agreement; tanween fath is written on indefinite accusatives (`زرّاً`, `بيتاً جديداً`); numbers stay Arabic-Indic. Kept on purpose: `الليوان` (a room with no fusha equivalent), `كشتبان`, `الكناري`, `نمط شامي` (names the embroidery tradition, not the language), and the proverb `الجار قبل الدار`. `دقّ` is used for knocking throughout (`دقّتان`, `الدقّات`). Word choices a native reader may want to revisit: `دبّ` for the teddy (was `دبدوب`), `أريكة` (was `كنباية`), `مودّة` for the fourth closeness level (was `غلاوة`), `ياسمينة مجفّفة` for the pressed jasmine (was `مكبوسة`), `درزة` for a seam, `سهما اليمين واليسار` (dual) in the tea-table label, `نلعب معاً` and `دثِّر للنوم` on the two care buttons (kept neutral because the doll may be Lina or one of the boys), and `filmLine3`, where Noor was feminine (`تاركة`) and is now masculine like everywhere else.

Recaptured with the fusha text on the 6.9-inch simulator: the five Arabic store screenshots in `ios/store/screenshots/ar/` and `ios/store/review/store-card-ar.png`. Still showing the old wording: the Arabic film exports (`film/exports/*-ar-*.mp4`, the thumbnail), whose captions are burned in.
